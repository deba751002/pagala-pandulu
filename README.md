# Pagala ♥ Pandulu — Our Love Story

A cinematic love-story website (HTML, CSS, JavaScript + GSAP). No build step: open `index.html` or visit the GitHub Pages link.

## Edit content
Everything (names, dates, letter, reasons, photos) is in the `CONFIG` block at the top of `script.js`.

Photos go in `images/` — see `GEMINI_PROMPTS.md` for the list of file names.

## Update the live site
Any change pushed to the `main` branch goes live on GitHub Pages in about 1 minute.

- **From anywhere (browser):** open the repo on github.com and press `.` to open the web editor, edit, then commit.
- **From phone:** GitHub mobile app → repo → file → ✏️ edit → commit.
- **From this computer:** `git add . && git commit -m "your message" && git push`
